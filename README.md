# Cozy Fields: Minesweeper

Classic minesweeper to play offline: big tiles, 36 levels and a calm, cozy look.

- Google Play: https://play.google.com/store/apps/details?id=com.jeetech.g003
- Privacy policy: https://jeet-s.github.io/jeetech-g003/privacy.html
- Current version: 1.0.3

`game/` is the Expo (React Native) source as shipped; `store/` holds the listing and graphics.
